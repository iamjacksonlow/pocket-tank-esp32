Pocket Tank, one-button edition

Singapore's air quality, live bus times and an AI fish tank on one small board with one button. Install it from this page, no tools needed.

Install

  1. Plug the board into your computer with a USB-C cable that carries data (some only charge).
  2. Click Install and pick USB JTAG/serial debug unit from the list.
  3. Wait a minute or two. When it says Installation complete, the board restarts by itself.
  4. Connect it to Wi-Fi: on your phone, join the PocketTank-Setup network and pick your home Wi-Fi. You can also paste an LTA DataMall key there (optional).

Updating? Use the same button. It never erases your fish or your Wi-Fi settings.

One thing to know: the bus stops

This ready-made version shows two example bus stops in the city, and the alerts page uses the "City" weather area. To show the stops around your home, set them in firmware/main/user_config.h and build it yourself. The setup guide walks through it. The air quality pages work anywhere in Singapore as they are.

Which board?

Spotpear ESP32-S3 1.54" LCD board (sold for the XiaoZhi AI chatbot): ESP32-S3 N16R8, 240×240 screen, no touch, one BOOT button.

Other boards won't work: the screen will stay blank. Installing replaces whatever was on the board (for example XiaoZhi).

Having trouble?

My board isn't in the list

Hold BOOT while you plug in the cable, then click Install again. Also try another cable, and plug straight into the computer, not a hub.

The install fails or stops partway

Close anything else using the board, like a serial monitor or this page in another tab. Unplug, plug back in, and try again.

Start over with a clean board

This erases everything (fish and Wi-Fi settings included), then installs fresh.

In the pop-up, tick Erase device. Left unticked, it installs like the main button.

What gets installed?

The app, the 7.5 MB fish model and two small startup files. Your fish and Wi-Fi settings sit in a separate spot the main button never touches.
